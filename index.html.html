    How this connects to real accounts

    Every channel feeds the same classifier. Only the intake differs:

    • Email: the Gmail API with a read-only OAuth scope, plus push notifications so new mail is classified as it arrives.
    • SMS: an Android companion app with the SMS-receive permission. iPhones don't let apps read texts.
    • WhatsApp: personal chats have no public API. A companion app with Android's notification access can read incoming message text on the device. Business accounts can use the WhatsApp Business API.

    Ranking uses three layers: scam and hoax detection on the wording and links, a priority score from who sent it and what it asks, and Claude for drafting replies. Marking a message as spam or always important teaches the system for next time.
